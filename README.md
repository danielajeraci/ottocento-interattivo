# Dentro il vero

Sito didattico statico in italiano per la quinta superiore: Positivismo, Realismo, Naturalismo e Verismo.

## Uso

Aprire `index.html` in un browser. Non servono compilazione, dipendenze o account degli studenti. La pagina usa solo HTML, CSS e JavaScript locali. Funziona anche offline dopo aver scaricato i tre file principali.

La mappa ha quattro nodi esplorabili; il laboratorio comprende 12 quiz ragionati, 6 associazioni, 2 attività di analisi e riscrittura, 3 tracce per il colloquio e 8 carte di ripasso. I quiz salvano i risultati nel browser quando possibile. Le risposte aperte non sono salvate e non ricevono voti automatici.

## Materiali

Rielaborazione didattica delle tre fotografie nella cartella originale `Didattica italiano`. Le fotografie non sono incluse nel sito pubblico. La sezione Fonti distingue le integrazioni e collega i testi di Balzac, Zola e Verga. Gli esempi narrativi del laboratorio sono inventati e dichiarati come tali.

## GitHub Pages

Caricare i file di questa cartella nella radice di un repository. In Settings → Pages scegliere Deploy from a branch, ramo `main`, cartella `/ (root)`, quindi Save. Il file `.nojekyll` evita l’elaborazione Jekyll. Gli asset hanno percorsi relativi e funzionano anche sotto il percorso del repository.

Documentazione ufficiale: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Il sito non è pubblicato fino al completamento del caricamento e dell’attivazione di Pages nell’account GitHub del titolare.
